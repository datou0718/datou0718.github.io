# World map geometry

`world-land.json` is the unmodified `land-110m.json` from
[world-atlas 2.0.2](https://cdn.jsdelivr.net/npm/world-atlas@2.0.2/land-110m.json),
derived from Natural Earth's 1:110m land boundaries. Natural Earth data is
[public domain](https://www.naturalearthdata.com/about/terms-of-use/).

The geometry is bundled locally and rendered with an Equal Earth projection
by `TravelMap.tsx`. It is application data; edit visits in `content/travel.json`.
